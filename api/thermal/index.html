    Thermal API¶

    The fuel-cell thermal-management system (Class I / Class II, see Thermal Management), the geometric heat-exchanger toolkit, the ram-air drag model, and the heat-source/sink network scaffold.

    Thermal-management subsystem¶

    Thermal-management system (TMS) of the fuel-cell aircraft: Class I and Class II.

    ThermalManagementSystem is the subsystem attached to the aircraft (aircraft.tms).

    Class I (default): the heat-exchanger mass is the peak fuel-cell heat divided by a specific power, EnergyInput['HEX Specific Power H2'] [W/kg]. No drag, no pump power.

    Class II: a geometric model of the FC_SPEC architecture:

    stack --coolant--> [HEX 1: coolant -> liquid H2] --> [HEX 2: coolant -> ram air] --> pump
    • The coolant leaves the stack at T_op and returns TMS Coolant DeltaT colder.
    • HEX 1 warms the hydrogen from saturated liquid at the supply pressure to T_op - TMS H2 Approach DeltaT (fixed duty, enthalpy rise from CoolProp para-hydrogen, latent heat included).
    • HEX 2 rejects the remaining heat to ram air.
    • The heat absorbed by the reactants inside the stack (H2 and cathode air entering below T_op) is subtracted from the stack heat.
    • Each HEX role is sized with the geometric families of :mod:.hex, using as many identical units in parallel as needed to keep each unit within the per-unit mass and volume caps.
    • The pump power is Vdot * dP_loop / (eta_pump * eta_motor) (an electrical load on the fuel cell); pump and motor masses come from specific powers.
    • The ram-air duct drag comes from :func:.ram_air.ram_air_drag.

    The design point is chosen over the mission (:meth:ThermalManagementSystem.SizeForMission): every mission point carrying at least half of the peak heat is tried as the design point; each resulting geometry is rated at every mission point with the hardware fixed (coolant flow set by the pump, air flow by the intake capture area), and the lightest geometry that rejects the heat everywhere is kept.

    def RamDragCoefficient(self, result, wing_area):
    """Ram-air drag of ``result`` as a drag-coefficient increment referred to
    ``wing_area`` [m^2], at the dynamic pressure of its design point. Applied as a constant
    increment it scales the ram drag with the dynamic pressure at every flight condition."""
    p = result.design_point
    _, _, rho = self._ambient(p['altitude'])
    q_dyn = 0.5 * rho * p['V_inf'] ** 2
    if q_dyn <= 0.0 or wing_area <= 0.0:
        return 0.0
    return result.ram_drag / (q_dyn * wing_area)

    def RateAtPoint(self, result, point, capped=True):
    """Heat the FIXED hardware of ``result`` rejects at another mission point.

    Coolant flow = the pump's design flow; ram-air flow = intake capture area x rho x V
    (flap fully open); each unit's U is recomputed from its geometry at the new flows.
    With ``capped`` (default) the rejected heat is limited to what is required (the
    hydrogen to its target temperature, the ram air by the flap); ``capped=False`` returns
    the full capacity of the hardware at that point.
    Returns ``(q_rejected [W], q_required [W])``.
    """
    cond = self._conditions(point)
    q_req = cond['Q_ext']
    if q_req <= 0.0:
        return 0.0, 0.0
    T_op = cond['T_op']
    coolant = self._coolant(T_op, result.mdot_coolant)
    by_role = {u.role: u for u in result.units}
    q1, T1 = 0.0, T_op
    u1 = by_role.get('coolant_to_h2')
    if u1 is not None and cond['h2'].mdot > 0:
        n = u1.n_parallel
        q1 = n * rate_design(u1.design, coolant.split(n), cond['h2'].split(n))
        if capped:
            q1 = min(q1, cond['q_h2_target'])
        T1 = T_op - q1 / coolant.C
    q2 = 0.0
    u2 = by_role.get('coolant_to_ram_air')
    mdot_air = result.capture_area * cond['rho_amb'] * cond['V_inf']
    if u2 is not None and mdot_air > 0:
        n = u2.n_parallel
        air = self._ram_air(cond, mdot_air)
        q2 = n * rate_design(u2.design, coolant.with_inlet(T1).split(n), air.split(n))
        if capped:
            q2 = min(q2, q_req - q1)
    return q1 + q2, q_req

    def SizeAtPoint(self, point):
    """Size the Class-II TMS at one mission point.

    ``point`` is a dict with ``name, Q_fc [W], altitude [m], V_inf [m/s TAS],
    mdot_h2 [kg/s]`` (see ``Mission.thermal_profile``). Returns a
    :class:`FCThermalManagementResult`.
    """
    cond = self._conditions(point)
    Q_ext, T_op = cond['Q_ext'], cond['T_op']
    coolant = self._coolant(T_op, 1.0)
    coolant = coolant.with_mdot(Q_ext / (coolant.cp * self.coolant_delta_T))
    units, shortfall = [], 0.0
    dP_hot_max = self.loop_pressure_drop

    # HEX 1: coolant -> hydrogen (fixed duty).
    q1 = cond['q_h2_target']
    T1 = T_op
    if q1 > 0 and coolant.mdot > 0:
        u1 = self._size_role('coolant_to_h2', coolant, cond['h2'], q1, dP_hot_max, 1.0e4)
        if u1 is None:
            q1 = 0.0
        else:
            units.append(u1)
        T1 = T_op - q1 / coolant.C
    else:
        q1 = 0.0

    # HEX 2: coolant -> ram air (the remainder).
    q2 = Q_ext - q1
    mdot_air, drag_raw, capture = 0.0, 0.0, 0.0
    if q2 > 1.0:
        T0 = cond['T_amb'] + cond['V_inf'] ** 2 / (2.0 * 1005.0)
        dT_air = min(self.ram_air_delta_T, self.ram_air_max_effectiveness * (T1 - T0))
        # the core may not lose more than the dynamic pressure the intake recovers
        q_dyn = self.ram_recovery * 0.5 * cond['rho_amb'] * cond['V_inf'] ** 2
        u2 = None
        if dT_air > 0 and q_dyn > 0:
            air = self._ram_air(cond, 1.0)
            mdot_air = q2 / (air.cp * dT_air)
            air = air.with_mdot(mdot_air)
            u2 = self._size_role('coolant_to_ram_air', coolant.with_inlet(T1), air, q2,
                                 dP_hot_max, q_dyn)
        if u2 is None:
            shortfall += q2
            mdot_air = 0.0
        else:
            units.append(u2)
            capture = mdot_air / (cond['rho_amb'] * cond['V_inf'])
            drag_raw = ram_air_drag(q2, mdot_air, cond['T_amb'], cond['P_amb'], cond['V_inf'],
                                    V_core=u2.design.v_cold, dP_core=u2.design.dP_cold,
                                    eta_ram=self.ram_recovery)
    # (if no family could do the H2 duty, q1 = 0 and the ram air takes the whole heat)

    V_dot = coolant.mdot / coolant.rho if coolant.mdot > 0 else 0.0
    pump_power = V_dot * self.loop_pressure_drop / (self.pump_efficiency * self.pump_motor_efficiency)
    pump_mass = pump_power / self.pump_specific_power + pump_power / self.pump_motor_specific_power

    return FCThermalManagementResult(
        design_point=point, units=units, mdot_coolant=coolant.mdot, mdot_ram_air=mdot_air,
        capture_area=capture, pump_power=pump_power, pump_mass=pump_mass,
        hex_mass=sum(u.mass for u in units), hex_volume=sum(u.volume for u in units),
        ram_drag=max(drag_raw, 0.0), ram_drag_raw=drag_raw,
        heat_balance={'stack': max(point['Q_fc'], 0.0), 'reactants': cond['q_reactant'],
                      'HEX H2': q1, 'HEX ram air': q2 if mdot_air > 0 else 0.0,
                      'unmet': shortfall},
        heat_shortfall=shortfall)

    def SizeForMission(self, points):
    """Choose the design point over the mission and size the Class-II TMS there.

    Every point carrying at least ``CANDIDATE_HEAT_FRACTION`` of the peak heat is tried
    as the design point; each geometry is rated at every point (:meth:`RateAtPoint`);
    the lightest geometry with a worst shortfall within ``FEASIBILITY_TOLERANCE`` is
    kept. If none qualifies, the one with the smallest worst shortfall is kept.
    Stores and returns the chosen :class:`FCThermalManagementResult` (its
    ``candidates`` attribute holds the selection table).
    """
    Q_max = max(p['Q_fc'] for p in points)
    trials = [p for p in points if p['Q_fc'] >= self.CANDIDATE_HEAT_FRACTION * Q_max]
    table = []
    for p in trials:
        res = self.SizeAtPoint(p)
        worst, worst_at = 0.0, None
        for other in points:
            q_rej, q_req = self.RateAtPoint(res, other)
            if q_req > 0:
                gap = max(0.0, (q_req - q_rej) / q_req)
                if gap > worst + 1e-9:
                    worst, worst_at = gap, other['name']
        table.append({'point': p['name'], 'result': res, 'mass': res.total_mass,
                      'worst_shortfall': worst, 'worst_shortfall_at': worst_at,
                      'feasible': worst <= self.FEASIBILITY_TOLERANCE})
    feasible = [t for t in table if t['feasible']]
    if feasible:
        chosen = min(feasible, key=lambda t: t['mass'])
    else:
        chosen = min(table, key=lambda t: (t['worst_shortfall'], -t['mass']))
    result = chosen['result']
    result.candidates = [{k: v for k, v in t.items() if k != 'result'} for t in table]
    self.result = result
    return result

    def report(self):
    """Print a short summary of the last Class-II sizing."""
    r = self.result
    if r is None:
        print("TMS: Class I (specific-power model)" if self.Class == 'I' else "TMS: not sized")
        return
    print(f"TMS Class II: design point '{r.design_point['name']}' "
          f"(Q_fc = {r.design_point['Q_fc']/1e3:.0f} kW)")

        print(f"  {u.role:20s}: {u.n_parallel:3d} x {u.design.family:17s} "
              f"{u.design.weight:6.1f} kg {u.design.volume:7.4f} m3 per unit, "
              f"{u.q/1e3:7.1f} kW{flag}")

          f"{r.mdot_ram_air:.1f} kg/s, drag {r.ram_drag:.0f} N")
    print(f"  total TMS mass: {r.total_mass:.1f} kg")
    if r.heat_shortfall > 1e-3 * max(r.design_point['Q_fc'], 1.0):
        print(f"  WARNING: {r.heat_shortfall/1e3:.1f} kW of heat not rejected")

    Heat-exchanger sizing¶

    Geometric heat-exchanger (HEX) sizing toolkit for the Class-II thermal-management system.

    Contents, top to bottom:

    1. Fluid streams and CoolProp property look-up (:class:FluidStream, :func:coolprop_fluid).
    2. The epsilon-NTU method (:func:effectiveness, :func:ntu_required, :func:thermal_solve).

    3. Three exchanger families, each sized from its geometry:

    4. :class:PlainTubeBankSizer -- liquid in tubes, gas across a plain staggered bank; Gnielinski inside, Zukauskas outside, Jakob pressure drop.

    5. :class:FinnedTubeBankSizer -- liquid in tubes, gas across annular-finned tubes; Gnielinski inside, Briggs & Young outside, Schmidt fin efficiency.

    6. :class:PlateFinSizer -- liquid in plain channels, gas in offset-strip fins; Manglik & Bergles j/f factors.

    7. :class:HeatExchangerSelector, which picks the lightest family for one duty.

    Sizing and rating are consistent by construction. Every sizer turns a candidate geometry plus a required area into a built layout (tube count, rows, length, layers ...), then recomputes U from the real velocities of that layout and iterates the area until the two agree. The same :meth:HeatExchangerSizer.compute_U is used to rate a built geometry at another flight condition (:func:rate_design), so rating a design at its own design point returns its design duty.

    All U values are referred to the area stored in HEX_Design.A (the total gas-side area for finned surfaces), and the inner-side and wall resistances are scaled by the area ratio.

    FinnedTubeBankSizer ¶

    FinnedTubeBankSizer(spec)

    Bases: _TubeBankSizer

    Annular-finned staggered tube bank (aluminium fins on steel tubes).

    Gas side: Briggs & Young (1963), Nu = 0.134 Re^0.681 Pr^(⅓) (s/l)^0.2 (s/t)^0.1134, with Re on the tube diameter and the maximum velocity; the candidate fin spacing is kept inside the correlation's tested range of s/t. Fin efficiency: annular fin with Schmidt's equivalent-radius approximation. The transverse pitch is set from the FIN diameter, so fins of adjacent tubes never overlap.

    Gas-side pressure drop: N_rows * f * rho * Vmax^2 / 2 with f = 1.5 Re^-0.2, an approximation without a literature source; a validated finned-bank friction correlation (e.g. Robinson & Briggs) should replace it.

    def effectiveness(ntu: float, cr: float, arrangement: FlowArrangement) -> float:
    """Exchanger effectiveness for the given NTU, capacity ratio Cr = C_min/C_max and
    arrangement (Incropera & DeWitt, Fundamentals of Heat and Mass Transfer, Table 11.3)."""
    if ntu <= 0.0:
        return 0.0
    if cr <= 1e-9:                                     # one stream has (near) infinite C
        return 1.0 - math.exp(-ntu)
    if arrangement == FlowArrangement.COUNTERFLOW:
        if abs(1.0 - cr) < 1e-9:
            return ntu / (1.0 + ntu)
        e = math.exp(-ntu * (1.0 - cr))
        return (1.0 - e) / (1.0 - cr * e)
    if arrangement == FlowArrangement.PARALLEL:
        return (1.0 - math.exp(-ntu * (1.0 + cr))) / (1.0 + cr)
    if arrangement == FlowArrangement.CROSSFLOW_UNMIXED:
        return 1.0 - math.exp((1.0 / cr) * ntu ** 0.22 * (math.exp(-cr * ntu ** 0.78) - 1.0))
    if arrangement == FlowArrangement.CROSSFLOW_CMAX_MIXED:
        return (1.0 / cr) * (1.0 - math.exp(-cr * (1.0 - math.exp(-ntu))))
    if arrangement == FlowArrangement.CROSSFLOW_CMIN_MIXED:
        return 1.0 - math.exp(-(1.0 / cr) * (1.0 - math.exp(-cr * ntu)))
    raise NotImplementedError(arrangement)

    def ntu_required(eps_target: float, cr: float, arrangement: FlowArrangement,
                 ntu_max: float = 50.0, tol: float = 1e-9) -> float:
    """NTU that gives ``eps_target`` (bisection on :func:`effectiveness`, which is monotone in
    NTU). Raises ValueError if the effectiveness is not reachable with this arrangement."""
    if not (0.0 < eps_target < 1.0):
        raise ValueError(f"required effectiveness {eps_target:.4f} outside (0, 1)")
    if effectiveness(ntu_max, cr, arrangement) < eps_target:
        raise ValueError(f"effectiveness {eps_target:.4f} not reachable with "
                         f"{arrangement.value} at Cr={cr:.3f}")
    lo, hi = 0.0, ntu_max
    while hi - lo > tol * max(hi, 1.0):
        mid = 0.5 * (lo + hi)
        if effectiveness(mid, cr, arrangement) < eps_target:
            lo = mid
        else:
            hi = mid
    return hi

    def thermal_solve(hot: FluidStream, cold: FluidStream, UA: float,
                  arrangement: FlowArrangement) -> float:
    """Heat [W] a given UA transfers between two streams (rating with epsilon-NTU)."""
    if UA <= 0.0 or hot.T_in <= cold.T_in:
        return 0.0
    cmin, cmax = min(hot.C, cold.C), max(hot.C, cold.C)
    eps = effectiveness(UA / cmin, cmin / cmax, arrangement)
    return eps * cmin * (hot.T_in - cold.T_in)

    Ram-air duct drag¶

    Net drag of a ram-air heat-exchanger duct (Meredith-type momentum balance).

    The duct is modelled as: intake + diffuser -> heat-exchanger core -> nozzle.

    1. The free stream (V_inf, T_amb, P_amb) is decelerated adiabatically in the diffuser; the total temperature is conserved and the intake recovers the fraction eta_ram of the free-stream dynamic (ram) pressure, p0_1 = P_amb + eta_ram (p0_inf - P_amb) (1.0 = ideal intake). Ram recovery is defined on the dynamic pressure, not on the absolute total pressure, because at these speeds the dynamic pressure is only a few percent of the total pressure.
    2. In the core the air is heated at the core Mach number (Rayleigh flow, giving the small total-pressure loss due to heating at low speed) and loses the core friction pressure drop dP_core computed by the exchanger sizer.
    3. The nozzle expands the air isentropically back to ambient pressure.

    The net drag is D = mdot * (V_inf - V_exit). Heat addition raises V_exit (Meredith effect), friction and intake losses lower it. A negative value means net thrust.

    The model has no spillage, external (cowl) drag or duct-wall losses beyond eta_ram, so it is a lower bound on the installation drag.

    def ram_air_drag(Q: float, mdot_air: float, T_amb: float, P_amb: float, V_inf: float,
                 V_core: float, dP_core: float, eta_ram: float = 1.0) -> float:
    """Net drag [N] of a ram-air cooling duct (see module docstring).

    Args:
        Q: heat added to the air [W].
        mdot_air: air mass flow [kg/s].
        T_amb: ambient static temperature [K].
        P_amb: ambient static pressure [Pa].
        V_inf: true airspeed [m/s].
        V_core: air velocity in the exchanger core [m/s].
        dP_core: core (air-side) pressure drop [Pa].
        eta_ram: fraction of the free-stream dynamic pressure recovered by the intake.
    """
    if mdot_air <= 0.0 or V_inf <= 0.0:
        return 0.0
    T0_1 = T_amb + V_inf ** 2 / (2.0 * CP_AIR)
    p0_inf = P_amb * (T0_1 / T_amb) ** (GAMMA / (GAMMA - 1.0))
    p0_1 = P_amb + eta_ram * (p0_inf - P_amb)

    T_core = T0_1 - V_core ** 2 / (2.0 * CP_AIR)
    M1 = V_core / math.sqrt(GAMMA * R_AIR * T_core)
    T0_2 = T0_1 + Q / (mdot_air * CP_AIR)
    M2 = _subsonic_mach_from_T0_ratio(_rayleigh_T0_ratio(M1) * T0_2 / T0_1, M_lo=M1)
    p0_2 = p0_1 * _rayleigh_p0_ratio(M2) / _rayleigh_p0_ratio(M1) - dP_core

    if p0_2 <= P_amb:                    # no expansion left: the air leaves at ~zero speed
        V_exit = 0.0
    else:
        V_exit = math.sqrt(2.0 * CP_AIR * T0_2 * (1.0 - (P_amb / p0_2) ** ((GAMMA - 1.0) / GAMMA)))
    return mdot_air * (V_inf - V_exit)

    Heat-source / sink network scaffold¶

    Scaffold for a future heat-exchanger network (thermal-management) module.

    Hydrogen-electric aircraft must reject large amounts of low-grade heat — from the fuel-cell stack, power electronics, motors — and can use the cryogenic fuel and ram air as heat sinks. A full thermal-management module would size a network of heat exchangers, coolant loops and pumps. This module provides the interfaces and a minimal balance solver that such a module will build on, so the rest of the code can already register heat sources (e.g. the fuel cell's Q_thermal, the tank's heat leak) and sinks today.

    Design (mirrors the powertrain graph and the efficiency-model registry):

    • :class:ThermalConditions — the operating point (altitude, speed, ambient temperature).
    • :class:HeatSource — something that produces heat to reject at a temperature.
    • :class:HeatSink — something that can absorb heat (ram-air cooler, fuel heat sink, ...).
    • :class:HeatExchangerNetwork — collects sources and sinks and solves a heat balance.
    • concrete helpers (:class:ConstantHeatSource, :class:CallableHeatSource, :class:RamAirSink) plus a registry for future custom components.

    The solver here is intentionally simple (does total rejected heat fit within total sink capacity?). It is the seam where a detailed effectiveness-NTU / coolant-loop model will go.

def from_aircraft(cls, aircraft, T_source=None):
    """Build a starter network from a designed aircraft's heat sources.
